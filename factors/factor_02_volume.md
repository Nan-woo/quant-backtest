# 因子 02 — 纯成交量

## 逻辑

不看任何价格指标，只看成交量变化。

买入：近 5 天 >= 3 天量比 > 1.2（冷清被打破，有人在动）
卖出（三条规则 OR）：
  ① 10 天内缩量 >= 7 天（没人气了，阴跌/慢涨 → 离场）
  ② 天量（量比 > 1.7）后缩量（暴涨暴跌 → 迅速止盈止损）
  ③ 入场 >= 3 天后又现 >= 3 天放量（持续放量 → 落袋）

核心假设：成交量的异常变化先于价格，量本身包含独立信息。

## 参数

- 超量阈值：量比 > 1.2
- 天量阈值：量比 > 1.7
- 入场窗口：5 天中 >= 3 天超量
- 出口①窗口：10 天中缩量 >= 7 天

参数稳定性：ve=0.8~1.2, vx=1.5~2.0 区间内 8-10/10 正收益，非常稳定。

## 回测结果（测试期 2024-2026，12 只股票）

测试期 11/12 正收益，高振幅组平均 +32%。

## 边界条件

通过 12 只股票分组分析：

| 特征 | 高分位（均收益） | 低分位（均收益） |
|------|-----------------|-----------------|
| 日均振幅 > 2.6% | +32% | +19% |
| 日均成交量 < 44M | +32% | +19% |
| 均价 > 47 元 | +33% | +17% |

**适用：振幅大 + 成交量偏低 + 股价偏高的股票。**
逻辑解释：高价筛选了投机资金 → 成交量信号更干净；波动大 → 量变化信号更多。

初始假设"适合散户票、不适合机构票"被数据推翻——低量组包含茅台、宁德时代等机构重仓股，因子效果反而更好。

| | 因子 01（偏离度） | 因子 02（纯量） |

| 数据维度 | 价格 | 成交量 |

| 科大讯飞测试 | -21.9% | +35.8% |
| 招行测试 | +31.4% | +18.3% |

因子 01 在招行最强，因子 02 在京东方/科大讯飞最强。互补发生在横截面（不同股票）而非逐日。

## 组合（50/50 等权）

- 测试期 11/12 正收益
- 滚动窗口交叉验证：50/50 组合 Sharpe 0.30~0.35，与"最优"权重（0.32）差距可忽略
- 结论：等权即最优——因子独立性本身让组合变稳，权重不重要
