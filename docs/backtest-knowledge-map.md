# 回测系统知识地图

## 项目分步路线

```
数据获取 → 数据清洗 → 策略信号 → 回测引擎 → 结果分析 → 可视化
```

### Phase 1：数据获取

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `pd.read_csv()` | 加载股票日线数据 |
| `pd.to_datetime()` | 把日期文本转成真正的日期 |
| `df.head()` / `df.info()` | 看一眼数据长什么样 |

### Phase 2：数据清洗

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `df.dropna()` | 去掉缺失的行 |
| `df.sort_values()` | 按日期排序 |
| 基本索引 `df[df["列"] > 值]` | 筛选数据范围 |

### Phase 3：策略信号

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `df["收盘价"].rolling(20).mean()` | 算 20 日均线 |
| `np.where(条件, A, B)` | 满足条件买，不满足卖 |
| `df["收益率"] = df["收盘价"].pct_change()` | 算收益率 |

### Phase 4：回测引擎

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `df.iterrows()` 或 `.iloc[]` | 逐行遍历，模拟每天 |
| 变量累加（`capital *= 1 + r`） | 算资金曲线 |
| 条件判断 `if signal == "buy"` | 执行交易逻辑 |

### Phase 5：风险指标

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `np.mean()` / `np.std()` | 平均收益、标准差 |
| 夏普比率公式 | `(年化收益 - 无风险利率) / 年化波动率` |
| `np.max()` / `np.min()` | 最大回撤 |

### Phase 6：可视化

| 需要的知识 | 用来做什么 |
|-----------|-----------|
| `plt.plot()` | 画净值曲线 |
| `plt.title()` / `plt.legend()` | 加标题、图例 |
| `plt.savefig()` | 保存图片 |

---

## 每个 Phase 用到的 Python 概念

### Phase 1-2：基础操作
- 变量、列表、字典
- `import`
- `pd.read_csv()`
- 用 `df["列名"]` 取列

### Phase 3：中间计算
- 函数（`def`）
- pandas 的 `rolling()` 窗口计算
- `numpy` 的 `where()` 条件判断

### Phase 4-5：核心逻辑
- `for` 循环遍历数据
- `if/else` 判断
- 数学运算累加
- numpy 统计函数

### Phase 6：收尾
- matplotlib 画图
- 文件保存
