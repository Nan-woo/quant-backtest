## 后续 Phase

### Phase 3：执行与仓位

| 子任务 | 学什么 |
|--------|--------|
| 3.1 交易成本 | 手续费 + 滑点对策略的影响 |
| 3.2 仓位管理 | 每次买多少？（凯利公式直觉） |
| 3.3 止损止盈 | 什么时候认错？什么时候落袋？ |

### Phase 4：统计验证

| 子任务 | 学什么 |
|--------|--------|
| 4.1 假设检验 | "这个结果是不是运气？"（t 检验、p 值） |
| 4.2 多重比较 | "测了 10 个参数选了最好的是过拟合吗？" |
| 4.3 鲁棒性 | 换股票、换时间段的检验方法 |
| 4.4 夏普比率 | 收益和风险的综合度量 |

### Phase 5：多标的 & 多因子

| 子任务 | 学什么 |
|--------|--------|
| 5.1 多股票回测 | 从 1 只到 N 只的架构调整 |
| 5.2 因子组合 | 两个信号怎么综合？加权？投票？ |
| 5.3 IC 分析 | 因子值和未来收益的相关性 |

### Phase 6：策略生存性

| 子任务 | 学什么 |
|--------|--------|
| 6.1 隐含假设 | 每个策略背后有 6~10 条看不见的假设 |
| 6.2 失效报警 | 给每条假设找一个可量化的"报警指标" |
| 6.3 策略休眠 | 报警触发时自动停掉策略，而不是等亏穿 |
