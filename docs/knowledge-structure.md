## 第 3 层：策略层（我设计的信号）

### 趋势跟随（追涨）
- 价格 > 均线 → 持仓
- 金叉死叉：短均线上穿长均线 → 买

### 均值回归（抄底）
- 跌到偏离均线 5% → 买，涨回均线 → 卖
- 双向：跌够买 + 涨够卖 ← 目前最好的策略 (+44.08%)

### 过滤器
- 趋势过滤器：ADX 判断"现在该不该交易"
- 成交量过滤器：缩量洗盘 → 放量阳线 = 买
- 趋势期跑策略，震荡期休眠

### 风险控制
- 止损：跌 20% 强制卖（对茅台从没触发过）
- **移动止盈**：从最高点回撤 15% 就跑——保护浮盈。对茅台效果一般（信号卖出本身够好），对单边暴跌的票可能救命
- 止损止盈参数有甜区：太紧（5%）被假摔震死，太松（30%）等于没加

### 策略鲁棒性（Phase 4.3 新增）
- **策略赚的不是方向的钱，是波动率的钱。** 只要跌后有间歇性反弹，不管最终股价涨跌都能赚钱
- 策略在价值蓝筹上不一定更有用——真正决定适用性的是"波动模式"：高振幅 + 有反弹 vs 单边趋势
- 同一策略换不同行业的股票跑——能跑通几只是几份自信，不能全通才算边界清楚
- **不能先射箭再画靶子：** 不能用策略在某股上的表现回推"这个股票有什么特征"，必须在跑数据之前定义筛选条件

### 仓位管理
- **Kelly 公式**：f* = (p×b - (1-p)) / b。赢了翻倍输了归零的硬币，60%胜率 → 最优押 20%
- 决定收益的不是"对了几次"，是"每次押多少"
- 实践中用半凯利，因为 p 和 b 估计不准
- **低频高确信策略 → 满仓进出即可。仓位管理的价值在多股票多信号时才体现**

## 第 4 层：统计层（我怎么检验策略）

- **样本外检验**：数据劈两半，前半找参数，后半验证
- **随机基准 / p 值**：1000 次随机买卖，看你排第几
- **过拟合**：测了 N 个参数挑最好的 → 那个最好含历史噪音。训练期选最优，测试期可能直接失效（亲眼验证了 MA10 阈值 7% 的例子）
- **Data Leakage（数据泄露）**：训练时偷看测试集 → 全段 p=0.023 缩水到测试期 alpha +10.5%
- **参数稳定性**：改参数 1%，结果变 30% → 过拟合预警
- **交叉验证 / 滚动窗口**：样本外的升级版，多劈几段轮流验证
- **策略失效判断**：亏损模式跟历史不像了 → 关掉

## 第 6 层：世界观层（我问过的哲学问题）

- **"知道全部参数就能完全预测吗？"**
  → 不能。三个原因：自由意志（人自己不知道明天会做什么）、世界随机性（新冠疫情）、反身性（预测改变预测对象）。

- **"大道至简还是一网打尽？"**
  → "大道至简"的"至"是动词——是你自己删减直到只剩最关键的东西。不是一开始就简单，是经历了复杂之后回到的简单。

- **"天文学方法也能量化吗？"**
  → 技术上能。但没有因果解释的因子迟早会炸。判断标准：这个因子背后有没有人类行为的逻辑？

- **"均线这种 K 线策略应该用处不大？"**
  → 均线不是预测，是无意识捕捉人群行为惯性（动量效应）。它是入门哑铃，不是比赛武器。真正的 alpha 来自基本面数据 + 另类数据。

- **"放量金叉为什么反而不赚钱？"**
  → 放量是最后一批追涨的人进场——你不是在确认，你是在接盘。

- **"趋势跟随和均值回归的区别？"**
  → 趋势跟随赌人群继续往一个方向跑。均值回归赌人群反应过度了。两种完全相反的世界观。

- **"没有免费午餐"**
  → 减少交易换更高收益（+30.49%），代价是吃了完整回撤（-47.53%）。收益是用风险换的。

- **价格行为学/技术分析的本质**
  → 不是玄学，是群体行为心理学用 K 线表达出来。缠论的"中枢"= 多空博弈平衡区。可以量化。
