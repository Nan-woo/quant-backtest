## 第 2 层：架构层（我理解的系统）

- AI 写代码，我做判断

## 第 3 层：策略层（我设计的信号）

### 趋势跟随（追涨）
- 价格 > 均线 → 持仓
- 金叉死叉：短均线上穿长均线 → 买

### 均值回归（抄底）
- 跌到偏离均线 5% → 买，涨回均线 → 卖
- 双向：跌够买 + 涨够卖 ← 目前最好的策略 (+44.08%)

### 过滤器
- 趋势过滤器：ADX 判断"现在该不该交易"
- 成交量过滤器：缩量洗盘 → 放量阳线 = 买
- 趋势期跑策略，震荡期休眠

### 风险控制
- 止损：跌 20% 强制卖（对茅台从没触发过）
- 移动止盈：保护浮盈（还没学）

## 第 4 层：统计层（我怎么检验策略）

- **样本外检验**：数据劈两半，前半找参数，后半验证
- **随机基准 / p 值**：1000 次随机买卖，看你排第几
- **过拟合**：测了 N 个参数挑最好的 → 那个最好含历史噪音
- **策略失效判断**：亏损模式跟历史不像了 → 关掉

## 第 5 层：概念层（知道但还没学）

- 夏普比率：收益和风险的比值
- 移动止盈（trailing stop）：保护浮盈的止损线
- 多元因子：多个信号怎么综合
- IC 分析：因子值和未来收益的相关性
- 交叉验证（cross-validation）：比单次样本外更严的检验
- walk-forward：滚动窗口重新训练
- 策略容量 / 市场冲击成本
- 多重比较修正（Bonferroni）

## 第 6 层：世界观层（我问过的哲学问题）

- **"知道全部参数就能完全预测吗？"**
  → 不能。三个原因：自由意志（人自己不知道明天会做什么）、世界随机性（新冠疫情）、反身性（预测改变预测对象）。

- **"大道至简还是一网打尽？"**
  → "大道至简"的"至"是动词——是你自己删减直到只剩最关键的东西。不是一开始就简单，是经历了复杂之后回到的简单。

- **"天文学方法也能量化吗？"**
  → 技术上能。但没有因果解释的因子迟早会炸。判断标准：这个因子背后有没有人类行为的逻辑？

- **"均线这种 K 线策略应该用处不大？"**
  → 均线不是预测，是无意识捕捉人群行为惯性（动量效应）。它是入门哑铃，不是比赛武器。真正的 alpha 来自基本面数据 + 另类数据。

- **"放量金叉为什么反而不赚钱？"**
  → 放量是最后一批追涨的人进场——你不是在确认，你是在接盘。

- **"趋势跟随和均值回归的区别？"**
  → 趋势跟随赌人群继续往一个方向跑。均值回归赌人群反应过度了。两种完全相反的世界观。

- **"没有免费午餐"**
  → 减少交易换更高收益（+30.49%），代价是吃了完整回撤（-47.53%）。收益是用风险换的。

- **价格行为学/技术分析的本质**
  → 不是玄学，是群体行为心理学用 K 线表达出来。缠论的"中枢"= 多空博弈平衡区。可以量化。
