### 统计思维四课（撞到了问题 → 找到了工具）

**第一课：过拟合 = 记住了历史里的噪音，却以为它是规律**
- 我的直觉："有点像过拟合是吧"——在不知道术语之前，自己走了一遍完整的过拟合流程
- 本质：测 N 个参数选最好的 → 那个"最好"包含了历史偶然波动 → 未来大概率失效

**第二课：样本外检验 = 数据劈两半，前半找参数，后半只测不调**
- 我们写了 `phase4_out_of_sample.py`，把数据切成 2020-2023（训练）和 2023-2026（测试）
- MA35 训练期赚 **+76.33%**，测试期亏 **-25.70%**——教科书级的过拟合演示
- "全段最好: MA35 (+39.66%) ← 这个数字有水分"
- "策略在样本外输给了买入持有 —— 之前的'好'是过拟合"

**第三课：随机基准（假设检验的直觉）**
- 我的困惑："没懂随机买卖和 20 日均线买卖为什么能一起谈？"
- AI 用了 1000 次随机持仓跑给我看：MA15 赚 +24.60%，但有 379/1000 个随机策略跑得更好
- **核心洞察（我自己推导的）：**
  - "随机买是基准——如果随机买都有较大概率跟策略一样，策略其实不是最优策略"
  - "如果随机买都很多达到的话说明上涨趋势很强，赚钱并不是策略好的原因"
  - "应该有更好的策略收益大于随机买才对"
- p 值 = 策略被随机打败的概率。行业及格线是 p < 0.05，我的 MA15 是 p = 0.38

**第四课：策略失效判断 = 不是看亏了多少，是亏损模式跟历史还像不像**
- 60 天滚动收益分析：MA15 历史平均 +1.56%，最惨 -25.32%
- 历史从未出现过 60 天亏超 30%
- 判断链条：正常波动 → 历史罕见 → 从未出现 → 警报响了
- **数据背后的决策心路：**
  "赚钱 → 开心" / "亏 5% → 正常波动" / "亏 15% → 查模型" / "连亏 4 个月 → 看基本面是否大变" /
  "如果不知道原因 → 关了，不知道的情况下不下注"
- **关掉策略不是承认失败，是承认未知。在未知的市场上赌钱不是勇敢，是愚蠢。**

### 实盘与回测的关系

- Q: "一次实盘要几个月才能检验吗？时间成本好高" → 所以 90% 策略死在回测阶段，根本不配上实盘

- 量化员是守门员——不放任何一个可疑的策略过去

### 策略的隐含假设（我自己发现的概念）

- Q: "策略失效依赖于公司基本面没有太大波动、宏观格局没改变吧？还有适用条件边界？"
- **每个策略背后都有 6~10 条看不见的假设：** 基本面不变、市场风格不变、不进入大熊市、波动率匹配……
- "知道什么时候不用一个策略，比知道什么时候用它，更值钱。"
- → 大纲新增 **Phase 6：策略生存性**（隐含假设清单 → 报警指标 → 策略休眠）

### 策略容量：为什么小资金策略不能放大？

- 小资金进去没人在意 → 大资金买单本身推高价格 → 策略自己把自己搞死了
- 这是市场冲击成本（market impact）。策略逻辑没变，但你的手本身在改变价格。

### 过拟合 vs 策略随机性：容易混淆的两个问题（Day 2 补充清算）

昨天一口气过了四关统计概念，有点混乱。今天理清：

**问题 A：过拟合（参数维度）**
- "我测了 11 个参数，选了最好的 MA23——这个'最好'有多少是碰巧 fit 了历史噪音？"
- 解法：样本外检验（数据劈两半，训练期找参数，测试期验证）
- 昨天实证：MA35 训练 +76% → 测试 -25%

**问题 B：策略随机性（规则维度）**
- "就算我只测了 1 个参数（MA20），赚了 37%——这 37% 是因为规则会选好日子，还是因为茅台本来就在涨、碰巧持仓蹭到的？"
- 解法：随机基准 / p 值（1000 次随机持仓，看你的排名）
- 昨天实证：MA15 赚 +24.6%，但有 38% 的随机策略比它好 → p=0.38，不显著

**过拟合和策略随机性是两个不同层面的问题：**
- 过拟合 = 参数数字本身是靠反复试出来的
- 随机性 = 你的规则本身可能毫无预测力，只是蹭了趋势的便车
- 一个策略可能两个问题都有，也可能只有一个
- 昨天 MA15 两个都有：测了 11 个参数（过拟合） + 跑不过 38% 随机（不显著）

**检验的正确顺序：**
1. 先定规则，锁定参数（不要测 20 个再挑）
2. 跑随机基准 → 能跑赢 95% 的随机吗？
3. 能做样本外吗 → 训练期找到的规则，测试期还赚钱吗？
4. 换股票、换时间再测 → 只有茅台有效？只有 2020-2023 有效？
每一步都可能毙掉策略。

**交叉验证和 walk-forward 本质上都是"在历史上反复拷打策略，利用历史证据把不确定性的概率往下压"。但压不到零——"后面能否预测完全是未知数"（我昨天自己说的）。**

都归 Phase 4（统计验证）。

### 行业底层哲学（我问的深度问题）

**Q1: "股价由基本面、机构、宏观决定，均线这种 K 线策略应该用处不大？怎么用数学去拟合由真实世界变化造成的曲线？"**
→ 均线不是在预测，是在无意识捕捉人群行为的滞后反应（动量效应）。
→ 真正想拟合真实世界，需要基本面数据 + 另类数据（政策因子），不是纯量价。
→ 均线是哑铃，不是武器。练完肌肉去举更重的东西。

**Q2: "价格行为学、缠论这些技术分析，其实也有道理？"**
→ 本质不是玄学，是群体行为心理学用 K 线图表达出来。
→ 缠论的"中枢"= 多空博弈平衡区；威科夫的"吸筹区"= 筹码从弱手转强手。
→ 可以量化！缩量小阴线连跌、放量突破箱体沿、高位长上影放量——都能翻译成数学。

**Q3: "知道全部参数就能完全预测吗？"**
→ 不能。三个原因：人不知道自己会做什么（自由意志）、世界随机性（新冠疫情）、预测会改变预测对象（反身性）。这个系统是混沌的、自反身的，因为有人的参与而不可完整描述。

**Q4: "大道至简还是应该全面？"**
→ "大道至简"的"至"是动词——是你自己删减直到只剩最关键的东西。
→ 不是一开始就简单，是**经历了复杂之后回到的简单。**
→ 力学背景的直觉：连连续介质力学都是简化模型，量化的核心就是在精度和复杂度之间找最优解。

### Day 2 午前补充 — 简单策略的哲学 & 什么因子能信

**"好的策略就是均线+筹码峰+几个参数"——为什么简单的策略能赚钱？**
不是堆砌指标。是几个简单的工具从不同角度确认同一个判断：
- 均线 → 趋势方向
- 筹码峰 → 别人的成本在哪里（支撑/阻力）
- 参数 → 把成本博弈写成数学关系
三合一才是逻辑自洽的策略。互相印证，不互相补偿。"少即是多"不是只用一根均线，是经历了复杂之后回到的简单。

**"有人用天文学方法做量化，对吗？"**
技术上对——任何东西都能被量化。
但核心区别：有因果解释的因子 vs 纯碰巧相关的因子。
- 机构增持 → 股价涨：因果链清晰，失效时你知道为什么
- 金星逆行 → A股涨：测了 10000 个随机变量碰巧撞上的，失效时你完全不知道为什么
量化不排斥任何数据源，但排斥"不知道为什么赚钱"的策略。
判断标准："这个因子背后，有没有人类行为的逻辑？"
有 → 值得深挖。没有 → 迟早会炸。我自己昨天就推导出了这个逻辑——均线有用是因为它无意识捕捉了人群行为的惯性。

#### 金叉死叉：加了交叉条件，反而赚得更少

| 策略 | 收益 | 回撤 | 持仓 |
|------|------|------|------|
| 原策略（收盘>MA20） | +37.67% | -32.93% | 752天 |
| MA5/20 金叉死叉 | +20.81% | -44.20% | 752天 |
| 买入持有 | +25.99% | — | 全期 |

**我自己分析的原因（四条半）：**
1. 没有止盈止损，每次波段都是高买低卖
2. MA5 太敏感，任何短期噪音都能触发金叉，然后马上跌回来（追假反弹、卖假反转）
3. 死叉形成不了不是被套的原因——均线本身滞后，等死叉出来已经跌完了
4. 金叉在趋势市场里好用、在震荡市场里是灾难（事后验证：whipsaw）
5. (半条) "机构和量化反向收割"——方向对但因果错。不是针对你的策略收割，是因子拥挤（factor crowding）：大家都在用同一个信号，信号触发之前就被人抢跑了

#### 趋势过滤器实验：两次失败，一次半成功

**MA60 过滤器（失败）：**
"只在 MA60 以上（趋势期）启用金叉"。结果：收益从 +20.81% 暴跌到 +1.76%。
→ MA60 太慢了，判断出趋势来时已经走了一大半。**用一把慢刀切快肉。**

**ADX 过滤器（半成功）：**
ADX > 25 = 趋势，ADX < 20 = 震荡。结果：收益从 +20.81% 提升到 +24.86%。
→ 加了 4 个点，但回撤基本没变（-44% → -43%）。

**关键教训：**
ADX 只解决了"什么时候不进"（过滤假信号），没解决"什么时候出"（止损止盈）。
茅台 2020-2026 有 642 天在震荡、595 天在趋势——震荡时间比趋势还多。
金叉策略的根本问题不是买入时机不好，是**卖出时机太差**。

#### 止损实验：20% 止损对茅台是虚设

| 策略 | 收益 | 回撤 | 持仓 | 止损触发次数 |
|------|------|------|------|------------|
| 死叉卖出 | +20.81% | -44.20% | 752天 | — |
| 死叉+止损 | +20.81% | -44.20% | 752天 | **0 次** |
| **纯止损(无死叉)** | **+30.49%** | **-47.53%** | **1554天** | **0 次** |

**三个发现：**
1. 茅台从任何金叉入场点，从未累计跌超 20%——所以止损从未触发
2. 纯止损策略变成"买一次就永远不卖"——退化成买入持有
3. 死叉强制你下车 → 你每次下车都错过后续涨幅 → 积极交易反而赚得更少

**"没有免费午餐"的亲身证明：**
减少交易 → 收益更高 (+30.49%) → 代价是吃了完整的市场回撤 (-47.53%)

#### 回撤的三种痛（我自己问到的问题）

| 你感受到的痛 | 名字 | 算的是什么 |
|------------|------|-----------|
| "成本 10万，现价 14万，还赚 4万" | 盈利 | 现价 - 成本 |
| "最高到过 20万，现在才 14万" | **最大回撤** | 现价 vs 历史最高净值 |
| "浮盈从 10万跌到只剩 4万" | **利润回撤** | 浮盈缩水幅度 |

止损只保护本金（成本），不保护浮盈。保护浮盈需要**移动止盈（trailing stop）**——跟着最高价移动止损线。
但止盈本身没有完美答案——浮盈跌了跑不跑？你不知道明天是反弹还是崩盘。量化能做的只是在历史上找到一个"整体最优"的参数，不保证下次有效。

**我承认的困惑：** "有点懵了"——因为发现这个问题没有确定解。这不是我笨，是这个问题本身就没有完美答案。

#### Beta 和 Alpha 的深度讨论

**我自己的理解（AI 确认是对的）：**
- Beta = 买入持有的收益，是市场给你的，不需要能力
- Alpha = 你靠判断力赚的超额收益，减去 Beta 后剩下的
- 正 Alpha = 跑赢买入持有 + 跑赢 95% 随机买卖（p < 0.05），缺一个都不行

**我对 p 值的深刻理解：**
- p 值测的是"收益在时间维度上的分布是均匀还是聚集"
- 如果每天小涨——Beta 是均匀分散的——随便哪天进去都能蹭到——p 值高
- 如果少数几天暴涨——收益聚集在尾巴上——踩中才赚——p 值低
- "p 值就像导数——变化越平缓 p 越高"
- 我甚至自己悟出了**肥尾效应的本质**：真实收益率分布不是正态的，极端事件概率比想象的高

**我提出的关键质疑：** p 值高也不一定否定策略——如果策略逻辑本身就是"这段时间持仓"，那随机持仓跟策略持仓本来就应该差不多。p 值只能说明"这段数据不够硬，说服不了怀疑者"，不等于"策略无效"。没有证据证明有效 ≠ 证明无效。

### Phase 3.2：仓位管理（Kelly 公式 + 实战）

**硬币游戏（Kelly 直觉）：**
- 硬币正面 60%、反面 40%，赢了翻倍、输了归零，玩 100 次
- 押 5% → 赚太慢（+224%）；押 20% → 最优（+2428%）；押 50% → 连输几把就爬不起来了（-10%）；押 100% → 一把归零
- **决定最终收益的不是"赌对几次"，是"每次赌注占总资金的多少"**
- Kelly 公式：f* = p - q = 60% - 40% = 20%（简化版，盈亏比 1:1 时）
- 通用版：f* = (p×b - (1-p)) / b，b = 盈亏比

**应用到双向均值回归策略：**
- 胜率 64%，盈亏比 1.91 → Kelly 建议 45%
- 实践中用半凯利（~22%）或四分之一凯利——因为胜率和盈亏比本身估计不准

**三种仓位管理对比：**
| 方式 | 收益 | 回撤 | 平均仓位 |
|------|------|------|---------|
| 二值(0/100%) | +44.08% | -31.51% | 42% |
| 固定 25% | +11.96% | -8.21% | 10% |
| 信号强度 | +8.83% | -8.24% | 4% |

**核心发现：单策略单股票上，二值（全仓进出）反而最好。** 策略低频（6年11次），每次信号都是高确信度机会。仓位管理的价值在多股票多信号时才会体现。

### Phase 3.3：止损止盈

**三种退出方式：**
- **固定止损：** 锚在成本上，跌 X% 就认输。保护本金。
- **移动止盈：** 锚在最高浮盈上，从最高点回撤 X% 就跑。保护利润。
- **固定止盈：** 锚在成本上，赚 X% 就走。放弃尾巴，换取确定性。

**移动止盈参数扫描（茅台双向策略）：**
| 止盈线 | 收益 | 回撤 | 触发 |
|--------|------|------|------|
| 5% | +6.14% | -43.91% | 23次 ☠ |
| 10% | +41.91% | -28.64% | 8次 |
| 15% | +43.64% | -33.67% | 4次 |
| 30% | +44.08% | -31.51% | 0次 |

**结论：**
- 5% 太紧 → 被假摔震出去，死得比没止损还惨
- 10% 最均衡 → 收益没怎么降，回撤略微改善
- 30% 太松 → 跟没加一样
- **茅台这种均值回归票，信号卖出本身已经是最好的退出机制。** 止损止盈适用于趋势票（单边暴跌时救命）

### 最关键的理解突破：`shift()` 和 pandas 列运算

**问题：为什么三行 pandas 代码能算出整张表的收益，不需要写循环？**

用真实 CSV 数据（前 10 行茅台数据）逐行推演了完整流程：

1. **原始 CSV 长什么样** — date/open/close/high/low/volume 六列，date 是字符串
2. **代码处理后** — date → 日期类型 → 设为索引 → 列名改中文 → 加 ma → 加偏离度
3. **`for` 循环** — 只做一件事：逐天判断持仓（0 或 1），填满 `data["持仓"]` 列
4. **循环外的三行**：
   - `shift(1)` → 把持仓往下移一天（今天买，明天才享受收益）
   - `fillna(0)` → 第一天填空
   - `pos * pct_change()` → 持仓 × 涨跌 = 日收益，pandas 自动按日期对齐
   - `cumprod()` → 连乘出净值

**核心认知：** pandas 是表格运算——你给它两列，它自动同行相乘出第三列。不需要写 `for i in range()`。`for` 循环只负责"判断买卖"，pandas 负责"算钱"。

**我的原话（理解后自己说出来的）：** "shift 把持仓数据手动往前移一行，再把第一天补上 0，让持仓和每天涨幅对齐，然后后面两行进行 pandas 表格操作，把所有的值全部算出来。"

### 鲁棒性测试：推翻了自己的结论

**第一轮结论（被推翻）：** "策略适合价值蓝筹，不适合科技股"

**数据打脸：**

| 股票 | 策略 | 买持 | p 值 | 
|------|------|------|------|
| 茅台 | +58.7% | +41.2% | 0.171 不显著 |
| 招行 | +63.8% | +38.3% | 0.122 不显著 |
| 京东方 | -10.3% | +34.7% | 0.735 不显著 |
| 海螺 | +44.7% | -54.0% | **0.023 显著** |

**关键发现：**
- 茅台招行赚了最多但 p 值不显著——因为是牛股，随机持仓也赚 20%
- 海螺崩盘（买持 -54%），但策略反向赚了 +45%。随机持仓平均亏 24%——策略的 alpha 是真实的
- **我最初的分类就错了**：海螺不是"价值蓝筹"，是房地产崩盘中的周期股（峰值 47→谷底 16）；京东方也不是"趋势股不好"，是策略不适合它

**修正后的理解：策略赚的是"波动率的钱"，不是"方向的钱"。** 只要跌了之后有间歇性反弹（振幅够大），不管最终股价是涨是跌，策略都能赚钱。适合的是"波动大、有反弹"的股票，不适合"一跌不回头"或"一涨不回头"的。

### 海螺深度分析

19 笔交易，14 胜 5 负，胜率 74%：
- 前段（2020-2021）：连胜，每笔 +5%~15%，快速出场
- 后段（2022-2026）：陷入长持仓（最长 139 天），有小亏有大亏，但早期积累够扛

**每年振幅 30%-70%，策略就是捕捉这些振幅中的反弹波段。**

### 样本外检验：最值钱的教训

劈数据（训练 2020-2023 / 测试 2024-2026），网格搜索最优参数：

| | 策略 | 买持 | alpha |
|---|---|---|---|
| 训练最优（MA10 阈值 7%） | -15.3% | -6.5% | **-9.4%** ← 过拟合 |
| 原版（MA20 阈值 5%） | +3.2% | -6.5% | **+10.5%** 有效但弱 |

**全段 p=0.023 是偷看测试集算出来的，有水分。** 真正的样本外 alpha 从 90% 缩到 10.5%。训练集选出来的"最优"参数直接失效——因为它把一段特定时间的波动模式学死了，那段模式在测试期消失了。**教科书级的过拟合案例。**

### 方法论突破：不能先射箭再画靶子

**核心教训：**
> "根据策略分析股票什么特征、然后说'你看，策略适合这个特征'——这是先射箭再画靶子。"

正确流程应该是：
1. **先于数据定义因子逻辑** → "策略捕捉暴跌后技术反弹，要求：波动率够大、有反弹空间、非单边暴跌"
2. **逻辑 → 可度量特征** → 月度振幅 > 15% / 非暴跌（单月跌幅 < 30%）/ 涨跌天数比 > 0.8
3. **训练集筛选 → 测试集验证** → 用这套标准在训练集选股，测试集跑一次验证

**每一步的逻辑都在数据之前确定，不能在数据之后编故事。**

### 防止过拟合方法全景

| 方法 | 一句话 |
|---|---|
| 样本外检验 | 劈数据，后半验证 |
| 交叉验证 | 劈成 5 份，轮流验证 5 次 |
| 滚动窗口 | 一路滚着训、一路往后测 |
| 参数稳定性 | 改参数 1%，结果变 30% = 预警 |
| Bonferroni 修正 | 测了 100 个因子 → 显著性门槛 ÷ 100 |
| 减少参数 | 50 个砍到 5 个，过拟合空间自然小了 |

### 机器学习 vs 手动调参

**讨论澄清：**
- 网格搜索（Agent 跑排列组合）≠ 机器学习
- ML 本质：`model.fit(X, y)` — 模型自己发现规则，不是人预设规则然后穷举
- **人的价值不在跑得快，在特征工程（选什么喂给模型）、数据划分（怎么防止泄露）、结果解释（为什么这个因子有效）**
- Data Leakage（数据泄露）：ML 最大坑。训练时偷看测试集 → 模型在"复习"不是在"预习"

### 新增概念

- 鲁棒性 = "换一只股票还灵不灵"
- p 值检验 = "跑赢了多少随机策略"
- 样本外检验 = "训练集选参数，测试集只跑一次"
- Data Leakage = "训练时偷看了测试集" → 我有直观感受了
- 过拟合 = "在训练集上神，在测试集上鬼"
- **最关键的一个：先有逻辑再调参，不能先看结果再编故事**
